# Fly.io brand assets

Artwork is copied unchanged from the Fly UI repository at `ui-ex/priv/static/public/images/brand/`. The official usage guide and current downloads are at [Fly.io's brand guide](https://docs.fly.io/about/brand).

- `logo.svg` and `logo-inverted.svg`: landscape wordmark, used in the extension header.
- `brandmark.svg` and `brandmark-inverted.svg`: colour mark, used in empty states and Chrome icons.
- `brandmark-light.svg`: official monochrome mark for the GitHub button and primary actions.

The palette uses Fly UI's navy (`#281950`) and violet (`#7c3aed`). Inter, Mackinac, and Fragment Mono are bundled from `ui-ex/priv/static/public/fonts/` into `public/fonts/`; runtime font requests stay inside the extension. Chrome's 16, 32, 48, and 128 pixel PNG icons in `public/icons/` are rasterizations of the unchanged brandmark vector.
